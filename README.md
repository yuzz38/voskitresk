# Воск и Треск — лендинг

Одностраничный сайт для мастерской ароматических свечей «Воск и Треск» (Instagram [@voskitresk](https://www.instagram.com/voskitresk), Красноярск). Чистые HTML + CSS + JS, без сборки и зависимостей — достаточно загрузить папку на любой хостинг.

## Структура

```
index.html          — страница (10 блоков)
css/style.css       — стили
js/main.js          — интерактив
img/                — изображения (WebP + JPG-запасной вариант), иконки, og.jpg
robots.txt          — правила для поисковиков (Яндекс + Google)
sitemap.xml         — карта сайта с картинками
llms.txt            — GEO: краткая выжимка о бренде для нейросетевых поисковиков
site.webmanifest    — манифест и иконки для телефонов
```

## Блоки

1. Первый экран — логотип-«одна линия» рисуется сам, свечу можно зажечь касанием
2. Каталог — слайдер из 12 позиций, фильтр по коллекциям, выбор объёма 250/180 мл, «Настроение» показывает мудборд аромата
3. Из чего рождается свеча — формула «воск + аромат + стакан + фитиль = свеча»
4. Сибирские истории — обновлённые иллюстрации
5. Осенние саше — Яблочный штрудель, Дыхание осени, Тыквенный пирог
6. Сочетание — «Утро в центре города» и кофе
7. Отзывы — слайдер
8. Где купить — 9 точек и Яндекс Карта
9. Как заказать с доставкой
10. Подвал

## Как работает заказ

Посетитель добавляет свечи кнопкой «В заказ», список хранится в браузере. В панели заказа кнопка копирует готовый текст («Здравствуйте! Хочу заказать: …, Итого: …») и открывает Telegram [@borisenkaaa](https://t.me/borisenkaaa) или Direct — остаётся вставить сообщение.

## Перед публикацией

- **Отзывы в блоке 7 — демонстрационные тексты.** Замените их на реальные отзывы клиентов (в `index.html` блок отмечен комментарием `ДЕМО-ОТЗЫВЫ`).
- Домен `https://voskitresk.ru/` указан как пример — замените его в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt` и `sitemap.xml`.
- Цены на осенние саше не указаны — кнопка ведёт в Telegram. Если цена известна, добавьте её в блок 5.
- Карта — виджет Яндекс Карт по адресу, ключ API не нужен.

## Совместимость

Safari iOS 12+, Chrome / Яндекс Браузер / Firefox / Samsung Internet для Android, все современные десктопные браузеры. Учтены вырез экрана iPhone (safe-area), `100svh/100dvh` с запасным `100vh`, `-webkit-` префиксы, `prefers-reduced-motion`, клавиатурная навигация.
